# 요청 원문 확보 결과

확인일: 2026-09-19

## 1. Stone, Royset, Washburn (2016)
- 전체 PDF 저장: Stone_Royset_Washburn_2016.pdf (222 PDF pages)
- 원문 제공: https://ndl.ethernet.edu.et/handle/123456789/37779
- 다운로드: https://ndl.ethernet.edu.et/bitstream/123456789/37779/1/92.Lawrence%20D.%20Stone.pdf
- 출판사: https://doi.org/10.1007/978-3-319-26899-6
- 4장 Path-Constrained Search in Discrete Time and Space, 인쇄 pp.81–120. PDF 94쪽에서 시작.
- 6장 Constrained Search in Continuous Time and Space, 인쇄 pp.155–188. PDF 167쪽에서 시작.

## 2. Washburn (2002), Search and Detection, 4th ed.
- 해당 판본 전체/요청 절 PDF 미확보.
- ISBN: 9781877640179 (1877640174)
- 서지: https://books.google.com/books?id=cvc0AAAACAAJ
- 저자 페이지: https://faculty.nps.edu/awashburn/washbubk.htm (현재 2014년 5판 안내이므로 4판과 구분)
- 도서관 원문복사 요청: 2002년 4판의 random search 절. 정확한 절/페이지는 이 판본 원문 미확보로 확정하지 않음.

## 3. Koopman (1980), Search and Screening
- 1980년판 PDF/요청 절 스캔 미확보.
- ISBN: 0080231365 / 0080231357
- 국내 소장: https://library.kaist.ac.kr/search/ctlgSearch/posesn/view.do?bibctrlno=18189&se=b0&ty=B
- KAIST 청구기호 T57.97 .K66 1980, 등록번호 0023509.
- 원문복사 요청: sweep width 정의 및 lateral range curve 관련 절.
- 별도 1946년 원보고서 공개 경로: https://www.informs.org/Explore/History-of-O.R.-Excellence/Documents/Bernard-O.-Koopman-Search-and-Screening-1946
- 1946년판은 1980년판과 구성이 다르므로 1980년판 페이지로 인용하면 안 됨.

## 4. Eagle & Yee (1990)
- An Optimal Branch-and-Bound Procedure for the Constrained Path, Moving Target Search Problem.
- Operations Research 38(1), 110–114 (5쪽).
- 출판본: https://doi.org/10.1287/opre.38.1.110
- 1990년 출판본 PDF 미확보. 동일 제목의 1987년 NPS 기술보고서 저장: Eagle_Yee_NPS.pdf (15쪽, 저장소 표지 포함).
- 보고서 번호 NPS-55-87-015. 출판본과 문구/페이지 동일 여부 미확인.
- 저장소: https://hdl.handle.net/10945/30058

## 5. Trummel & Weisinger (1986)
- Technical Note—The Complexity of the Optimal Searcher Path Problem.
- Operations Research 34(2), 324–327 (4쪽).
- 출판사 전체 PDF: https://pubsonline.informs.org/doi/pdf/10.1287/opre.34.2.324
- 웹 조회 도구에서 application/pdf, 4쪽 확인. 로컬 다운로드는 사이트 봇 확인 화면으로 실패.

확보하지 못한 파일을 확보 완료로 표시하지 않았으며, 구매/기관 로그인/원문복사 신청은 수행하지 않았음.
